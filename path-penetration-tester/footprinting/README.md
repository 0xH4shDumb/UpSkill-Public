# Footprinting

Le footprinting est la première phase active d'un test d'intrusion. Avant de chercher des vulnérabilités, il faut comprendre ce qui compose l'infrastructure cible : quels services tournent, comment ils sont configurés, quelles informations ils exposent. Ce module couvre l'ensemble du processus, des principes d'énumération jusqu'à l'analyse détaillée de chaque protocole courant.
