# Processus de test d'intrusion

Le test d'intrusion suit un processus structure en phases distinctes, du cadrage juridique et contractuel jusqu'a la remise du rapport final. Ce module couvre la methodologie, les types de tests, les livrables attendus a chaque etape et le cadre reglementaire dans lequel s'inscrit l'activite de pentest.
