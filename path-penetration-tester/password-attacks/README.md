# Password Attacks

Les mots de passe restent le mecanisme d'authentification dominant, et leur compromission est souvent le point de bascule d'un engagement. Ce module couvre l'ensemble du cycle : des attaques distantes jusqu'au mouvement lateral, en passant par le cassage, l'extraction et la recherche de credentials sur les systemes et le reseau.
