# Documentation et reporting

Le rapport est le livrable principal d'un test d'intrusion. Ce module couvre l'ensemble du processus de documentation, de la prise de notes pendant le test jusqu'a la livraison du rapport final : structure des notes, types de rapports, composants essentiels, redaction des findings et outils de productivite.
