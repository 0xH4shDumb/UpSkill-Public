# Elevation de privileges Windows

L'elevation de privileges Windows transforme un acces utilisateur standard en controle total du systeme. Les vecteurs sont nombreux : privileges de tokens, groupes integres mal compris, permissions faibles sur les services, credentials exposes, kernel exploits, contournement de l'UAC. Ce module couvre l'ensemble du spectre, de l'enumeration initiale au durcissement.
